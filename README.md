# 密码生成器

在 8–10 位限制下生成包含大写、小写、数字、特殊符号的密码，兼顾词形助记和 Mac 美式键盘输入。默认 **10 位 + 词形助记 + 键盘友好**。全静态页面，零第三方运行依赖，不需要安装 npm 包。

## 使用

需要 Node.js 20 或更新版本。在终端执行：

```sh
git clone https://github.com/Douzi-Qishen/password-generator.git
cd password-generator
npm start
```

浏览器打开 <http://127.0.0.1:8754>。每次进入页面都会生成新的密码；可切换 8 / 9 / 10 位、词形助记 / 完全随机，独立开关键盘友好，生成下一条、复制、隐藏，或点击字符查看键位和 Shift 提示。停止服务按 `Ctrl+C`。

右上角“使用说明”按钮打开说明弹窗，可用关闭按钮、Esc 或点击遮罩关闭。点击“跟着键盘，轻松输入”区域（也可用 Tab 聚焦）后可直接敲键练习，无需输入框；Esc 或点击区域外退出。深色键显示当前按下的物理键，正确输入后自动前进并标记完成，输入错误时停留；Backspace 回退，重新练习清空进度。练习区分大小写，使用英文输入，不接受粘贴或拖入文本。仅聚焦的练习区域处理按键，不保存练习文本；隐藏或重新生成密码会清空练习进度。

端口被占用时使用 `PORT=8755 npm start`。服务只监听本机 `127.0.0.1`，只提供页面静态资源。不要直接双击 HTML，浏览器会限制 `file://` 模块加载。也可以用已有的本地静态服务器提供本目录。

## 线上体验与部署

[在线使用密码生成器](https://lab.douzi.wiki/password-generator/)。

这是一个完全静态的网页应用，可部署到 Nginx 或其他支持 HTTPS 的静态站点：

1. 发布 `index.html`、`styles.css`、`app.js`、`generator.js`、`favicon.svg`。
2. 保持文件位于同一目录；子路径部署时，将不带尾斜杠的目录地址重定向到带尾斜杠的地址。
3. HTML 和脚本使用 `Cache-Control: no-store`，并参考 `server.mjs` 设置 CSP 等响应头。不存在的资源应返回 404。
4. 使用 HTTPS，以支持 Web Crypto 和剪贴板 API。服务端只分发静态资源，密码始终在访问者浏览器内生成。

不需要在服务器运行 Node.js；本项目的 Node 服务仅供本机预览。

## 生成方式

**词形助记**

- 生成两段可拼读拟词，每段为 3 或 4 个字母。原辅音池 `bcdfghjklmnprstvwz` 和元音池 `aeiou` 保留，通过位置规则加入 `q/x/y`，不删除任何旧词形。
- 普通词形为 `OVE`（3 位）或 `OVOV`（4 位）。`O` 是原辅音池加 `y`，用于音节开头；`E` 是原辅音池加 `x`，用于词尾；`V` 是 `aeiou`。因此 `x` 不放音节开头，`y` 不当元音或词尾使用。
- 新增 `QUA`（3 位）和 `QUAE`（4 位）：`Q` 只能是 `q`，`U` 只能是 `u`，`A` 为 `aeio`。`q` 仅出现在词段开头并与 `u` 连用，避免孤立 q 或 quu；大小写仍逐字允许变化。
- 普通四字母词形按两组辅音元音显示拼读提示；其他词形整段显示，包括所有 qu 词形。词形是便于拼读的启发式拟词，不保证是真实英文单词、有特定含义或唯一读音；输入仍保留密码中的大小写。
- 再生成一段 2–4 位数字/符号，至少各含一个。该段可放首、中、尾。枚举所有总长为 8–10 位的合法组合。
- 每个字母均允许大小写，整串至少各含一个，不固定大写数量、位置或排除底排大写。键盘成本约束会影响其分布，并非每个位置独立以 50% 概率大写。数字与符号也不固定为恰好一个。
- 助记分段就是生成时的词形/数符边界，不再把随机串事后按固定长度截开。

**完全随机**

从全部大小写字母、数字和 32 种 ASCII 标点中抽取，四类至少各一个；不受词形语法限制。此时分组只辅助显示，随机空间更大。

**键盘友好是独立开关**

- 两种模式均允许全部 32 种 ASCII 标点，不再按是否需要 Shift 筛选符号。完整字符池为 94 个可见 ASCII 字符（不含空格）；词形助记仍使用上文的辅音和元音池。
- 开启时计算整串输入成本，8 / 9 / 10 位分别限定总成本不超过 **16 / 18 / 20**。不固定同手次数、Shift 字符数量或大写数量，各项可在总预算内互相权衡。
- 仅额外硬性排除相邻重复的物理键，包括大小写或符号变化，如 `aA`、`2@`；跨分段边界也计入。
- 关闭时不限制输入成本或重复键，页面仍显示成本供参考。

| 成本项 | 加分规则 |
| --- | --- |
| 相邻字符主键同手 | 每次 +3 |
| 新按下 Shift | 每次 +2，合计按键与小指操作负担 |
| 连续 Shift 换侧 | 在新按下成本之外，每次再 +3，表示双手协调负担 |
| 每只手跨排移动 | 相对该手上次输入主键的排位，每跨一排 +1 |
| 小指输入字符主键 | 每次 +2 |

按数字排、QWERTY 排、ASDF 主排、ZXCV 底排依次编号 0–3；两手初始都按主排（2）计算。即使中间另一只手输入，也保留本手上次行号。Shift 使用主键对侧的小指；连续使用同侧 Shift 可保持按住，只计一次按下。遇到不需要 Shift 的字符后再使用 Shift，需重新按下。连续两个字符改用另一侧 Shift 时，既计新按下，也计换侧协调成本。

权重和上限是本工具的**经验规则**，没有经过人体工学实验验证。跨排按手估算，不模拟每根手指轨迹、横向伸展或按键速度；不同个人指法可能有不同体验。成本越低表示模型估计的操作负担越少，不是密码安全分。

所有组合都使用 Web Crypto 安全随机数。先用动态规划（BigInt）准确计数整个合法空间，再从总空间抽取一个随机序号，按各模板/子树大小解码。不会等概率挑模板后误用总空间，也不会批量生成再挑最高输入评分。随机整数使用拒绝采样，避免取模偏差；没有 `Math.random` 降级。

计数状态同时包含词形后缀、四类字符覆盖、上次物理键分组、Shift 状态、另一只手上次行号及剩余成本。物理键按完整词形 token 成员关系、手、行、手指归组；例如 u 属于 U/V，aeio 属于 A/V，不能混为一组。数字与其 Shift 符号共享物理组，以准确排除同键重复。只保留当前友好配置的计数缓存，不随切换选项无限累积。

熵为 `log2(合法密码总数)`，已包括词形、大小写、分段位置、总成本上限及重复键限制。具体值在页面“生成方式与安全说明”中随选项更新。加入 q/x/y 后，词形助记 + 键盘友好的 8 / 9 / 10 位生成熵约为 **31.0 / 36.5 / 41.2 bit**，合法组合数分别为 **2,122,894,250 / 100,164,735,413 / 2,610,728,100,298**。词形助记、关闭键盘友好时约为 **38.5 / 44.9 / 50.7 bit**。完全随机模式的空间不变，10 位开启 / 关闭键盘友好分别约为 **53.5 / 64.8 bit**。

词形扩展前后的比较保持长度、大小写规则、符号集和键盘成本预算相同。开启键盘友好时，8 / 9 / 10 位空间增加约 **23.9% / 21.3% / 20.6%**；关闭时增加约 **24.7% / 24.9% / 24.9%**。熵只增加约 0.27–0.32 bit，不应把这次小幅扩展解释为大幅提高密码强度。

助记分隔点（`·`）仅用于显示，复制不包含分隔点或空格；密码本身的英文点（`.`）仍会保留。完整密码以主显示区为准。

## 强度的实际含义

安全随机源不能抵消短长度的限制；满足四类字符也不代表足以抵抗任意离线破解。可拼读词形和键盘友好规则都会缩小空间，更易记不意味着更难破解。更重视随机空间时可选择“完全随机”，或使用更长密码。页面不提供脱离威胁场景的“破解需多少年”。

如果目标系统允许，优先选择更长的随机密码或由足够多的独立随机单词组成的口令。每个账户独立使用，并开启多因素认证。本工具遵守要求只生成 8–10 位，默认推荐 10 位。

参考 [1Password 密码生成器](https://1password.com/zh-cn/password-generator)的随机、独立密码与易记口令思路。该网页未提供其内部算法；本项目是独立实现，并非 1Password 算法复刻。

## 本地与隐私

- 密码只存在当前页面内存，不通过网络发送，不写 localStorage、sessionStorage、Cookie 或文件。
- 页面不加载第三方代码、字体、分析服务或远程资源。服务端 CSP 禁止页面发起网络连接。
- 点击复制会写入系统剪贴板；系统剪贴板管理器或跨设备同步可能保留内容，由操作系统设置决定。
- 隐藏会同时遮挡主密码、记忆分组、拼读提示、字符按钮、左右手标记和键位提示；它只是视觉遮挡，不是内存加密。
- 不收集真实账户或现有密码。浏览器扩展和本机环境的可信性仍由使用者负责。
- 按键映射基于 ANSI / US QWERTY 和常见十指指法，不保证其他国家/地区布局相同。

## 界面

浅色液态玻璃界面：银白半透明面板、淡青与柔紫背景、分段控件和键帽高光。主页面只保留生成、助记、练习的必要信息，完整规则集中在说明弹窗。支持窄屏、减少动态效果及低透明度偏好；所有视觉效果在本地由 CSS 实现。
