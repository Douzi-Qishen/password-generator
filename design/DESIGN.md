# 密码生成器界面设计

当前设计参考：`liquid-glass-concept.png`。由内置 Image Gen 生成后，按用户要求再次精简；所有文字、按钮、背景材质和键盘均用本地 HTML / CSS 实现，参考图不参与运行时加载。旧版参考图 `reference.png` 仅保留作历史对照。

## 视觉方向与设计系统

- 苹果风格的浅色液态玻璃：银白半透明面板、淡青与柔紫背景、细亮边和背景模糊。玻璃材质是用户明确要求。
- 页面保持生成、分段记忆、键盘练习三部分。长度和模式在桌面并排，手机单列。
- 主文字 `#1b2432`、次级文字 `#526176`、强调色 `#21674f`、数字 `#945215`、符号 `#a52c63`。颜色之外仍有原始字符和状态文本。
- 系统中文字体与 SF Mono / Menlo，字体和素材不从远程加载。桌面主标题 44px、密码 72px、区块标题 18px、控件 12–14px。
- 面板圆角 24px（手机 20px），玻璃采用 56% 白色、24px 模糊、125% 饱和度和内侧高光。按钮用统一的轻反光材质；生成按钮加深绿色以确保白字对比度。
- 过渡 80–200ms，仅用于选择、点击和弹窗状态。支持减少动态效果、减少透明度以及无 backdrop-filter 的回退。
- 密码生成、词形规则、输入成本与生成熵计算不因视觉样式改变。

## 文案精简

- 移除主标题副文案、键盘友好长解释、练习区成本统计、重复操作提示和侧栏安全长文。
- 页头按钮简写为“使用说明”，完整名称仍供屏幕阅读器使用。规则、成本明细、安全信息及键盘操作说明集中到弹窗。
- “分段记忆”保留实际词形和小写拼读，不再重复“拼读”前缀；分组中点不进入复制内容。
- 练习区只有一行启动/聚焦状态、重新练习和进度。正确输入时不重复报进度；错误和完成时才显示额外反馈。
- 保留下一键、手指及 Shift 提示，因为它们直接服务输入练习。

## 设计落实

| 对照项 | 落实与必要调整 |
| --- | --- |
| 布局 | 保留三部分顺序、并排设置、集中操作按钮和右侧下一键；窄屏提示栏移至键盘下方。 |
| 字体 | 系统中文和等宽密码，按真实网页尺寸调整控件字号，避免概念图放大字造成拥挤。 |
| 色彩 | 淡青、柔紫、银白玻璃，与深色文字和绿色操作一致；降低概念图字符的高饱和度，提升对比度。 |

## 词形助记规则更新

- 沿用既有界面，在长度下方增加“词形助记 / 完全随机”，默认词形助记；键盘友好独立开关。
- 助记带按真实生成的词形边界显示，不固定为 3/3/余数。每段拟词下方补充小写拼读提示；隐藏时一并移除。
- 字符按钮下方标出左/右手，展示字符主键的换手次数；Shift 另计。
- 取消恰好一个大写及恰好一个符号，说明中只保留四类至少各一个，并更新真实生成熵。

## 综合键盘成本更新

- 继续保留词形与实际分段，键盘友好改为综合成本预算：换手、Shift 按下和换侧、按手估算跨排、小指主键操作共同计分。
- 不再只选无需 Shift 的符号，两种模式都使用全部 32 个 ASCII 标点。
- 键盘提示上方显示当前输入成本、主键换手比例和 Shift 按下次数；说明弹窗内展示各项明细、上限、完整符号集及模型假设。
- 明确区分输入成本与生成熵。前者是经验规则，后者由筛选后的真实合法空间计算；不使用主观“强密码”评级代替熵值。
- 隐藏密码时同时隐藏成本明细和输入节奏统计；保留与具体样本无关的规则说明与生成熵。

## q / x / y 词形扩展

- q 仅在词段开头与 u 连用，再接 a/e/i/o；x 仅作词尾；y 用于音节开头。保留原有所有词形、分段位置与键盘成本规则。
- 拼读分组由生成语法提供：普通四字母词形仍显示 2+2，qu 词形整段显示，避免将 qu 与后续元音拆开。
- 页面规则说明同步解释位置限制；生成熵按扩展后的真实空间更新，完全随机模式不变。

## 说明弹窗与敲键练习

- 说明入口放在页头按钮中，使用原生 dialog 弹窗承载内容、限制焦点范围并支持 Esc；关闭后返回入口按钮。
- 键盘区整体可点击或 Tab 聚焦，无独立输入框，保留进度和重新练习按钮；提示键用浅薄荷绿，实际按下键用深绿，完成字符加勾，错误保留当前位置并用文字提示。
- 输入仅在练习区域自身聚焦时处理，Esc 或点击区域外退出，正确字符推进，Backspace 回退；隐藏、切换配置或重新生成时清空练习进度和按键状态。
